我们**不会**获取您的 Apple ID 邮箱、姓名或通讯录。 - 若您选择隐藏邮箱（Apple 提供的「隐藏我的邮箱」选项），我们只会收到 Apple 生成的转发地址。 - 该登录方式仅在您主动点击入口时触发；若您不点击，不会发生任何 Apple 授权行为。 - 若您不启用 Apple 登录，可继续使用手机号短信验证码或一键登录，功能不受影响。 2. 设备与系统信息（必需） · 设备标识：由系统提供的设备唯一标识（系统无法提供时由 App 在您设备上生成一串随机标识）保存在您的设备本地，用于多设备登录管理、异常登录识别与消息推送通道绑定。我们不读取您的 IMEI、手机号等硬件标识作为登录凭证。 · 设备型号、操作系统名称与版本、App 版本：用于兼容性适配、问题排查与服务端日志定位。 · 应用运行状态信息：本应用的运行底座（DCloud App 引擎）在应用运行期间会读取设备与应用的运行状态信息（设备品牌及型号、处理器类型、屏幕参数、网络类型、IP 地址、User Agent、设备语言、时区、是否模拟器或已被 root、引擎生成的随机匿名设备标识符、应用名与包名、版本号、异常堆栈、引擎启动时间与内存占用），用于排查性能与故障，详见"六、第三方服务与 SDK 清单"。 3. 登录与操作日志（必需） · 请求时间、IP 地址、设备与 App 信息：我们可能记录您的登录记录与关键操作记录，用于账号安全审计、异常行为识别与防刷。 · 上述记录由服务端保存。如您希望了解、更正或删除自己的登录记录，可通过文末方式联系我们。 4. 内容消费记录（必需） · 您浏览、搜索、订阅、点赞的艺人 / 活动 / 场馆记录：用于记录您的操作历史、向您展示订阅动态，以及在「我的订阅」中列出您自己订阅的对象。 · 「我的订阅」列表**完全由您本人在应用内主动订阅（关注偶像 / 活动 / 城市）的行为构成**。我们**不会**使用您的浏览、消费记录通过算法自动生成、推荐或修改您的订阅关系，也不会替您新增或取消任何订阅。 5. 您主动填写的资料（可选） · 昵称、头像、性别、生日、国籍、电子邮箱、微信号、个人简介：仅在您于「我的 - 上传情报」允许您主动提交演出海报图片与文字描述，用于补充 App 内尚未收录的演出信息。该功能属于用户生成内容（UGC），我们按以下规则处理： 1. 处理范围：我们仅收集您在该页面主动提交的标题、文字说明与图片（每次最多 3 张，单张不超过 5MB，仅支持 jpg/jpeg/png/webp）。 2. 人工审核：您提交的内容不会直接发布，须经运营人员人工核实。我们会在审核队列中记录内容、提交时间与处理结果（通过、驳回或已收录），以便追溯。 3. 公开范围：经核实并被采用后，您提交的文字信息会作为活动信息公开展示在活动页面；您提交的图片可能被裁剪或调整后作为活动海报使用。**采用与否由我们根据信息真实性与完整性判断，您不因此获得任何对价或权益。** 4. 使用目的：仅用于核实与完善活动信息，不用于广告投放、算法推荐或任何形式的商业转售。 5. 保留期限：您的上报记录（含未采用的）在账号存续期间保存；账号注销后，除法律法规要求必须留存的部分外，我们将删除或匿名化处理。 6. 拒绝的后果：若您上传的内容涉嫌违反法律法规、侵犯他人合法权益（含著作权、肖像权、名誉权），我们有权不予采用、删除该内容并视情节限制您的上报权限；由此产生争议的，由上传者自行承担相应责任。 ──────────────────────── 五、我们如何共享、转让与公开披露 ──────────────────────── 我们不会与任何第三方共享您的个人信息，法律法规另有规定或经您另行明确同意的除外。 在以下情形下共享、转让或公开披露： 1. 获得您的单独同意 2. 与法律法规、行政法规或强制性国家标准要求相一致 3. 为保护用户或公众的人身财产安全所必需 4. 依法向司法、行政机关或监管机构提供 如果我们将您的个人信息共享给其他主体，我们会明确告知接收方的名称或类型、共享信息的范围与目的，并要求接收方按照法律法规和本政策处理个人信息。 ──────────────────────── 六、第三方服务与 SDK 清单 ──────────────────────── 6.1 第三方服务 本应用使用以下第三方服务，请注意其隐私政策： 1.
